# V7-B risk register (single current register)

Scope: risks of the `sbgv7` implementation as built on branch `research/v7b-final-validation` at HEAD `a6afa639` (code and tests identical to `5efcef74`, where the recorded run is 276 passed, 1 skipped). This file supersedes section 6 of `reports/phase2/MB_SECOND_STAGE_REVIEW.md`; its IDs R1..R13 are kept unchanged so that review stays traceable. New IDs start at R14. It does not replace the design-time registers under `reports/v7_design/` (they cover R01-R54 of the pre-implementation design).

Everything here is local macOS, Phase 2. Nothing is validated operating-system isolation. Likelihood and impact are qualitative judgements of this register's author from code reading and the recorded tests; none was measured. "Owner phase" names who must act: Phase 2 (done or documented), Decision (a user decision), Phase 3 (Linux/Docker/external inputs).

Status words: Open (not mitigated), Accepted (limit documented, no action planned), Ratified limitation (user decision recorded in `FINAL_SPECIFICATION_DECISIONS.md`), Fixed.
