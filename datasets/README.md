# datasets/

No data is stored here. This directory only documents where the evaluation inputs come from and how to obtain them.
All data below is **non-pristine** for SBG (already seen by the developers and by V5/V6/V7-B); none of it is a held-out
benchmark. See `research/benchmarks/INDEPENDENCE_AND_LEAKAGE_AUDIT.md` and `research/benchmarks/DATASET_INVENTORY.md`.

## What the V7-B exploratory evaluation uses (all already vendored in the repo, 4.8 MB under `external/`)

| Arm | Pairs | Source | Where in the repo | Acquisition if the vendored copy is lost |
|---|---|---|---|---|
| QuixBugs buggy/fixed | 31 | https://github.com/jkoppel/QuixBugs, commit `4257f44b0ff1181dedaedee6a447e133219fcebf` (MIT) | `external/quixbugs/{python_programs,correct_python_programs,json_testcases}`, `manifest.json` | `git clone` that repo, `git checkout 4257f44b...`, copy the three directories byte-for-byte |
| QuixBugs SP negatives | 85 | generated from the fixed programs by this repo's semantics-preserving transformers | `external/quixbugs/variants/` | regenerated by the V5 pair generator (`scripts/generate_v5_pairs.py`); not re-derived in V7-B |
| BugsInPy units | 55 (9 not driven) | https://github.com/soarsmu/BugsInPy at commit `11c5f1eea954a42132cfd06bf257766a7963e0fd`; upstream code fetched at the buggy/fixed commits recorded in the manifest | `external/bugsinpy/units/`, `manifest.json` | `external/bugsinpy/README.md` describes the extraction; per-project licences apply and are listed there |
| Synthetic CHANGED / EQUIVALENT | 78 / 72 | SC/SP transformations of the authored corpus in `benchmark/` | `benchmark/datasets/`, `benchmark/corpus/` | in repo |

Totals: 321 pairs (31 + 85 + 78 + 72 + 55). 9 BugsInPy class units are not driven (312 driven); the primary analyses use 258 pairs after excluding 57 UNLABELLED and 6 SUSPECT_LABEL. Exact source paths, selection rules and denominators: [`docs/DATASET_PROVENANCE.md`](../docs/DATASET_PROVENANCE.md). The synthetic pairs are read by `experiments/v7b/k1_spike.py` from `benchmark/datasets/v8` and `benchmark/datasets/v10_independent`; despite the directory name they are not independent of V7-B development. Truth rules per arm are in `research/evaluation/EXPLORATORY_RESULTS.md`.

## Independent data: not available yet

The confirmatory gate K5 (>= 60 projects, >= 250 independent divergent pairs, kappa >= 0.7, clean leakage audit) is
not met and no sealed holdout exists. Candidate sources (PyBugHive, SWE-bench-Live, Defects4J, ...) with licences and
build feasibility are assessed in `research/benchmarks/DATASET_INVENTORY.md`; none has been acquired or run.
If you acquire one, keep it out of git (large), record URL, commit and SHA-256 in
`research/benchmarks/DATASET_PROVENANCE.csv`, and do not run V7-B on it until the split is sealed
(`research/benchmarks/FINAL_BENCHMARK_PROTOCOL.md`).
