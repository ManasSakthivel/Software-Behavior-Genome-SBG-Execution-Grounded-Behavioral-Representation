# SBG V8: IEEE Access manuscript

**Title:** When Is an Empty Difference Set Reassuring? Evidence-Conditioned False-Assurance Risk for No-Divergence Verdicts in Differential Regression Analysis.

**Status:** second-round revision, compiled with pdfLaTeX (`main.pdf`, 29 pages, 23 tables, 12 figures, 6 algorithms; third round). Round 1 is in commit `df612db0`. Changes since round 1 are listed in `SECOND_ROUND_SCIENTIFIC_REVISION.md`. It is not peer reviewed, and the empirical results are exploratory and come from development data. Before submission, the author must supply the affiliation, e-mail and biography; they are marked in `main.tex`.

## Build

The manuscript uses the official IEEE Access class, `ieeeaccess.cls`, from `ACCESS_latex_template_20260513` (ieeeaccess.ieee.org). The class, fonts and logos are copied into this directory. The class needs **pdfLaTeX**; XeLaTeX and tectonic fail on `spotcolor.sty`.

```
cd paper/IEEE_ACCESS_V8_FINAL
pdflatex main && bibtex main && pdflatex main && pdflatex main
python3 scripts/check_manuscript.py      # cites, refs, inputs, figures, placeholders, doi/url
```

This build was run on 2026-11-20 with TinyTeX (TeX Live 2026, `~/Library/TinyTeX`). Result:
- 0 errors and no undefined references or citations;
- BibTeX printed no warnings;
- the remaining overfull boxes are at most 6.5 pt, apart from the class's own header and `\maketitle` artefacts, which the unmodified official template also produces.
