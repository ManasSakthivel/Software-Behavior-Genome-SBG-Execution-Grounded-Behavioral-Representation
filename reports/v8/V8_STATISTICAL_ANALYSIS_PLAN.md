# V8 statistical analysis plan (implementation-level; DEVELOPMENT / EXPLORATORY status)

Implements `research/v8_final_design/06_EXPERIMENTAL_PROTOCOL.md` in `sbgv8/stats.py`, `calibrate.py`, `baselines.py`, `evaluate.py`. Nothing here is a Phase 3 analysis; the development records (`datasets/v8/dev_records.jsonl`) are design-exposed, so every output carries the banner **DEVELOPMENT DATA, EXPLORATORY, NOT INDEPENDENT VALIDATION** (emitted whenever any record has a split other than `evaluation`/`holdout`).

## Estimands
- Coverage c = P(NDO) over all y-known pairs. Selective false-assurance risk R = P(Y=1 | NDO). Joint risk J = c*R. R is undefined at c=0 (reported as not estimable, never as 0).
- y=None pairs are excluded from risk estimation, counted in `n_unresolved_y_none`, and a worst-case sensitivity (unresolved NDO pairs counted as false assurances) is reported for the rule baselines.

## Model (calibrate.py)
Transparent L2-penalised logistic regression of Y on phi(E), fitted on **eligible** pairs only (no witness; V7-B-style verdict via `profile.v7b_style_decision` not DIVERGENT_OBSERVABLE; no hard blocker). Count features enter as log1p; all features standardised. Pre-declared directions enforced as box bounds in L-BFGS-B: more act_frac / branch_cov_min / mu_* / n_same / n_rep / obs_react / n_eff* / repro_frac / chan_complete / prov_ok / integrity_ok / env_ok => lower risk (coef <= 0); lossy_frac => higher risk (coef >= 0). ERS response features have no pre-declared direction (free sign). Penalty grid {0.3, 1, 3, 10} chosen by inner-fold log loss. Decision: DIV precedence kept; NDO iff eligible and risk <= tau, else INSUFFICIENT.
**Eligibility choice (deviation to be stated):** V7-B blocker codes `changed_region_not_activated` and `budget_exhausted_s0` are treated as SOFT (they restate graded coverage that act_frac measures). Treating them as hard makes act_frac constant among eligible pairs and the coverage-only baseline vacuous. A strict run (every blocker hard) is reported as a sensitivity (`strict_blockers=true`).
Optional Platt/isotonic recalibration on a separate fold (`Model.recalibrate`), not used in the primary analysis. Conformal risk control for the JOINT risk J (`crc_threshold`) is EXPLORATORY: valid only for exchangeable project units, monotone bounded loss, model fit disjoint from the calibration set, guarantee in expectation, not for the ratio R, not conditional.

## Resampling, folds, thresholds
- Unit of resampling = project (cluster bootstrap, 10,000 resamples primary, seeded `default_rng([seed, crc32(label)])`, same convention as `scripts/analyze_results.py`). Same seed => identical resamples across systems, so differences are paired.
- Intervals: percentile and BCa (jackknife over projects) for the primary differences.
- Nested project-grouped CV: 5 outer folds by project (a project is in exactly one fold, asserted). Inside each outer-train set, 3 inner project folds choose lambda (log loss) and the thresholds tau_alpha (alpha in {0.10, 0.15}; largest coverage whose one-sided 95% cluster-bootstrap upper bound on selective risk <= alpha, computed on inner out-of-fold risks). The outer test fold is touched only by `predict_risk/decide` (no y); this is verified by a test that corrupts the test fold's labels and checks outputs are unchanged.
- Full CEC (baseline 8): per outer fold the ERS features are computed with the fold's CEC-without-ERS model; minor known optimism: inner tuning folds contribute to that ERS predictor. The outer test fold is not contaminated.
- Pooled out-of-fold predictions are scored. Models from different folds have different intercepts, so matched-coverage ranking uses the **within-fold average rank** of risk among eligible pairs (ties stay tied); calibration metrics use raw probabilities.

## Matched-coverage comparison (primary)
At coverage c* the lowest-risk eligible pairs are issued until coverage equals c* (fractional at ties, hence exact and deterministic). c* = coverage of the V7-B fixed gate on the same data (primary), plus the grid {0.2, 0.3, 0.4}. c* above the eligible share is reported as not achievable (nan), not extrapolated. Primary family (Holm): CEC vs baseline 7, vs baseline 3 (at its own operating point), vs baseline 6 (random abstention; 1,000 seeded draws for the point estimate, expectation used inside the bootstrap). H2 requires difference >= 5 pp AND the one-sided 97.5% lower bound > 0. Secondary families (separate, not in the Holm set): H1a (log-loss b9 vs b7), H3 (b8 vs b9, log loss and matched risk), H4 (calibration slope/intercept; not assessable without an independent holdout).
Reported alongside: Brier (with base-rate Brier), log loss, calibration intercept (slope fixed at 1) and slope, reliability bins, ECE under 6 binnings (never alone), risk-coverage curve, coverage at risk <= alpha (a) optimistic same-data curve value and (b) honest nested-threshold value, abstention rate, DIV recall on Y=1, project-macro R, leave-one-feature-group-out (7 groups), Spearman/VIF redundancy table.

## Baselines
b1 plain DT; b2 B1 + repetition (quarantined/nondeterministic input => INSUFFICIENT); b3 V7-B gate (recorded `v7b_verdict`); b4 coverage-only gate (full activation AND branch floor 0.80); b5 coverage-gated B1 (activation floor only); b6 matched random abstention; b7 coverage-only calibration (act_frac, branch_cov_min); b8 full CEC (full_profile + ERS); b9 CEC without ERS; ablations cov_rep, cov_mult, cov_infl, cov_prov, full_profile (= b9) and multiplicity-only (mu_min). Registry: `sbgv8.baselines.REGISTRY`.

## Power and precision
`stats.power_report` uses the actual cluster structure of issued NDO pairs: cluster sizes, ANOVA-ICC of the error indicator, design effect 1+(m-1)icc, effective n, normal half-width, crude MDE for a paired difference (McNemar normal approximation, assumed discordance 0.15, 80% power). Status is downgraded to **pilot/exploratory** when issued NDO < 100 or projects < 60 (stated in output). Non-significance is never read as no effect.

## Validation of the pipeline itself
Synthetic records with known truth (tests/v8/_synth.py): planted multiplicity effect recovered by CEC-without-ERS (and not by coverage-only); an ERS stand-in carrying hidden information is detected as gain; an ERS stand-in that is noise is reported as no gain; random abstention at equal coverage yields no risk gain; bootstrap CI coverage >= 85% on simulated clustered data; no project in two folds; test-fold labels cannot change test-fold outputs; deterministic replay; hand-computed matched-coverage cases.
