# V8 interface contract (coordination document; one source of truth with `sbgv8/schema.py`)

Branch `research/v8-implementation` (from `research/v8-final-design` e8ca1c12). V7-B (`sbgv7/`, `tests/v7`, `tests/v6`, results, artifacts) is read-only. Do NOT commit; the lead commits. Do not edit files you do not own. Do not run the full test suite (run only your own `tests/v8/test_<yours>*.py`, `.venv/bin/python -m pytest`). No network use except where stated. Phase 3 actions (VMs, external repos, human adjudication, holdout scoring) are forbidden.

## Data flow
raw V7-B evidence / live engine -> `adapter`/`collect` (A) -> `EvidenceRecord` (schema.py) -> `profile.build_profile` (B) -> features -> `perturb`/`ers` (B) -> response features -> `calibrate` (C) -> risk + decision -> `evaluate` (C) -> tables. Adjudication/manifest/splits (D) govern labels and project-aware splitting. `EvidenceRecord.y` must never be read by profile/perturbation/policy code (only by calibrate fitting and evaluation).
