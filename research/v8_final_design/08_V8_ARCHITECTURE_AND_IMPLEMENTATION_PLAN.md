# 08 V8 architecture and implementation plan (not implemented in this sprint)

One architecture; V7-B is untouched and additive. New code lives in a new package `sbgv8/` (offline modules first).
| Module | Inputs | Outputs | Responsibility and contract | Depends on | V7-B reuse | New code | Tests | Failure conditions |
|---|---|---|---|---|---|---|---|---|
| V7-B (baseline) | pair, inputs, config | verdict, evidence log | historical engine, S0-S2, witness | none | all | none | existing 286 tests | as Phase 2 |
| V8-A trusted collection | pair, inputs | authenticated observation records | parent-side collection of observations over an authenticated channel from an isolated child; external trust anchor for the log head; no verdict computed in the child's address space | Linux/Docker environment (Phase 3) | `isolation.py` ideas, `records.py` format | collector, anchor, forgery harness | adversarial forgery suite incl. the red-team probe | forged record accepted -> blocking |
| V8-B evidence profile | recorded evidence (V7-B or V8-A) | phi(E) with D1..D8, provenance | pure function of recorded evidence; contract: deterministic, no execution, documented per dimension (05) | records, harness extension for D2 | `finalize` hits/branches, run records | profile extractor, provenance schema, influence capture | golden-file tests per dimension; invariance tests | missing fields -> dimension flagged not imputed |
| V8-C perturbation | E, operator | E', delta(E'), s(E') | operators T_del, T_dup, T_mask post-hoc (pure `finalize` on altered parts); T_irr, T_bud, T_aug run the engine | V8-B | `runner.finalize` (pure), engine for new runs | operators, property-test fixtures, response profile | P1,P2,P4 deterministic tests; fixtures for P3,P5,P6 | operator changes fixed quantities -> test fails |
| V8-D calibration and policy | phi, rho, labels (calibration only) | risk estimate, threshold tau, verdict with risk | tier-1 monotone penalised logistic; project-grouped CV; threshold rule; optional CRC; never changes DIV | V8-B, V8-C | `decide` (DIV precedence kept) | model, folds, thresholding, report generator | grouped-CV leakage test (no project in two folds); calibration tests on simulated data with known truth | label leakage, tau chosen on test fold |
| V8-E evaluation and package | all of the above, dataset | tables, figures, hashed registration, replication package | pre-registered analysis scripts, hashes, archive | all | `scripts/p2_*` patterns | analysis, registration, packaging | determinism of analysis, hash match | any deviation logged |
## Sequence
M0 freeze registration drafts (06) -> M1 V8-B on recorded Phase 2 evidence (development only; verifies extraction and property tests, no claims) -> M2 V8-C post-hoc operators and P1,P2,P4 -> M3 V8-D on development data with simulated labels to test the pipeline (leakage, calibration of the method on synthetic truth) -> M4 D2 influence feasibility study on development programs (go/no-go: if influence cannot be measured reliably, drop D2 and report that) -> M5 V8-A and Linux validation (Phase 3, needs user authorisation) -> M6 dataset and adjudication (Phase 3) -> M7 freeze, holdout scoring, analysis -> M8 manuscript.
M1-M4 touch only the new package and recorded development data; no external execution. M5-M7 are Phase 3.
