## 4. Overlapping blocker analysis

- CLASS and CONTAINER co-occur in the same cases for the class-based data structures (`bucket`, `seekable`, `IndexedSet`), because they are constructed from an iterable.
- CALLABLE and DEFAULT co-occur where a callable is a defaulted parameter (`memoize`, `all_unique`, `flatten`, `bucket`).
- DEFAULT is the most common category (12 cases). Eight get it from the entry signature. Four get it only from the harness: schedule `90bfdf355` and `f19998bcf` (the `every(interval=1)` call the test makes), funcy `6cfcd4eec` (the input function's keyword-only default `language='en'`), and boltons `d0a284fc7` (the `IndexedSet(other=None)` constructor the test calls). Removing harness calls would not remove these defaults, because the tests make those calls.
- Five cases have four categories (schedule `90bfdf355`, `f19998bcf`, `bcfa35789`; funcy `e148cc9ab`; more-itertools `2b8d5cddc`), and eleven have three or more. Compatibility would require every listed category to be supported for a case, not just one.
