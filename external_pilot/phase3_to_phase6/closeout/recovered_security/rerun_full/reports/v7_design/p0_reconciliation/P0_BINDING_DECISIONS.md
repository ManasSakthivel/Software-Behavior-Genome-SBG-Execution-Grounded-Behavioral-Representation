# P0 binding decisions (authority for all reconciled documents)
Derived from the contradiction audit (65 contradictions: 10 Blocking, 31 Major), the red-team report, the isolation verification, and the power analysis. Where a reconciled document disagrees with this file, this file wins. Reasons: see the contradiction matrix and red-team report.

D1 **Verdicts (pair-level, per declared scope and input set), mutually exclusive by precedence:** (1) `DIVERGENT_OBSERVABLE`: >=1 replay-confirmed witness where an OBSERVED CHANNEL (return value, exception type/message class, declared side effects) differs on aligned, deterministic-confirmed runs. Absorbing/monotone: more exploration never revokes it (unless replay fails, which is an invalid-evidence event that voids that witness). (2) `INSUFFICIENT(reason_code)`: no confirmed witness AND (sufficiency < S1 OR alignment failed OR unresolved nondeterminism OR capture incomplete OR budget/sandbox failure OR signature/entry mismatch not handled). (3) `NO_DIVERGENCE_OBSERVED(S1|S2|S3)`: no confirmed witness, alignment valid, sufficiency >= S1. Precedence: 1 > 2 > 3. **There is no equivalence verdict anywhere.** `EQUIVALENT`, `SAME`, `PASS`, `VERIFIED`, `implicit pass` are prohibited as outcomes; bounded equivalence exists only as a separately named FORMAL CLAIM (`BOUNDED_EQUIVALENCE_PROVEN`) from the optional formal tier with its stated domain.
D2 **Internal-only divergence is NOT a verdict.** It is an advisory annotation `internal_divergence` (none|observed|unknown) attached to NO_DIVERGENCE_OBSERVED/INSUFFICIENT pairs, produced only if the optional state-abstraction module is enabled. Its truth class `INTERNAL_ONLY` cannot be defined independently of the SBG abstraction/alignment on real regressions (red-team Q3, Blocking), so: no confirmatory hypothesis (H7/H8) depends on it; it is confined to an exploratory pilot on authored-by-construction mutants with an independent reference state-dump tool; the P0 ground-truth protocol applies to that pilot only. Validation-matrix row "internal change masked by outputs" is a pilot diagnostic, not a gate.
D3 **Sufficiency S0-S3** has ONE definition, in P0_VERDICT_AND_SUFFICIENCY_SPECIFICATION.md. It is a conjunction of floors on separately reported factors (determinism-confirmed, instrumentation completeness, changed-region activation, input-diversity/budget), never a scalar score alone. All thresholds are UNVALIDATED defaults until a development split calibrates them; the plateau-based criterion is not allowed to confer S3 on its own (it rewards weak explorers). Other documents cite the spec and never restate thresholds.
D4 **Evidence taxonomy** (7 classes): direct observation, derived observation, inferred fact, formal proof, missing observation, invalid observation, uncertain observation; one canonical mapping to schema entities (see P0_EVIDENCE_TAXONOMY_AND_SCHEMA_AUDIT.md). Every verdict resolves to an evidence-ID chain.
D5 **Modules:** core = A, B, C, D, G, H, I, K, L. E (state abstraction and invariant mining) is an OPTIONAL extension for the V7-A pilot only. F is not a subsystem (projections inside G/H). J optional, off by default. Capture tiers L0-L3 with explicit completeness. Fabric stores replay recipes plus hashed event streams (events regenerated on replay), not full event logs by default (red-team Q7: 10-50x overrun).
D6 **Scope: V7-B is the primary target** (sufficiency-aware, witness-based differential comparison with adaptive exploration). V7-A (internal-state value) is an optional gated pilot (<=12 weeks, effect of interest +10pp, authored suites with independent truth), attempted only after V7-B shows headroom; it is never a precondition for V7-B success.
D7 **Baselines are like-for-like:** same-budget differential testing (B1) and coverage-guided differential fuzzing (B2) receive the same diff-derived region information when V7's explorer uses it, or V7's explorer is also run diff-blind; sufficiency-based abstention is applied to baselines equally; false-assurance is defined identically for all systems (an abstaining system makes no assurance claim; "implicit pass" is prohibited). Budget unit = CPU-seconds including all V7 overhead; holdout cost estimate 292-875 CPU-hours must be budgeted explicitly.
D8 **Statistics (from the power simulation):** confirmatory superiority claim only at an effect of interest of +10pp (requires about 60 projects / about 240-320 independent divergent pairs; 40 projects gives ~63% power at +10pp and ~22% at +5pp); +5pp is exploratory; the -2pp non-inferiority claim is dropped (needs ~8000 pairs); H7 is estimation-only; H8b cannot be confirmatory. Sizes quoted are simulation results under ASSUMED discordance and ICC, to be re-run on development estimates before sealing. Thresholds are not relaxed to make experiments pass.
D9 **K gates (single definition):** K1 real-pair feasibility (>=100 runnable real pairs from >=8 projects): fail -> STOP. K2 capture determinism and activation census (isolation rebuilt, determinism-confirmed rate and baseline activation measured on the K1 pairs): fail -> one redesign cycle of B, second failure -> STOP. K3 exploration lift (activation >=60% and >=+15 points over replay on the development set): fail -> PIVOT to V7-B with replay-plus-structure-aware exploration only (no directed exploration claim). K4 core thesis (sufficiency-aware witness comparison beats same-budget B1/B2 on the development set per the pre-declared metric): fail -> PIVOT to V7-B' = sufficiency-aware differential testing without the explorer/impact/state modules and without any novelty claim beyond the evaluation protocol; if V7-B' also shows no benefit over B1 -> STOP. K5 benchmark/adjudication readiness (power-sized per D8: >=60 projects, >=250 independent divergent pairs, kappa>=0.7, clean leakage audit) before any sealed-holdout unseal: fail -> no confirmatory evaluation (exploratory report only). Gates are numbered G0-G8 everywhere.
D10 **Isolation (verified findings: thread in host process, runaway thread keeps burning CPU, no rlimits, child processes survive, sys.settrace(None) evades tracing, os._exit kills host, network not denied):** the existing runner is not acceptable for any V7 claim and survives only as `v6_compat`. V7 capture = fresh child process per run, setrlimit, process-group kill, tracing set up outside user-code reach (settrace evasion detected), network denial and filesystem write confinement via sandbox-exec on macOS / container `--network none` on Linux; each property must pass an experimental check in P1 (only sandbox-exec network/write denial was observed to work in P0).
D11 **Equal-footing exploration:** exploration may use the changed-region map (static, label-free) but never labels, never benchmark identity, never outcomes of other pairs; any tuning of explorer hyperparameters uses only the development set; seeds are pre-declared.
