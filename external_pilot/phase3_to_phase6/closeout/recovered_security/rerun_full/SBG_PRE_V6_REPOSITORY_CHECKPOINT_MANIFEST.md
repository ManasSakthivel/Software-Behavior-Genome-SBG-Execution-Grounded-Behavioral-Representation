1. **`reports/external_validation/`:** Contains all multi-benchmark external validation reports, repaired QuixBugs test harnesses, Bugs.jar (Java) test runners, Codeflaws (C) Clang execution drivers, diagnostic CSVs, permutation tests, and leakage audits.
2. **`reports/v6_investigation/`:** Contains all 15 SBG V6 scientific investigation deliverables, technical audits, mathematical formulations, literature reviews, research questions, experimental plans, risk registers, and master redevelopment proposals.
3. **`reports/recovery_programme/`:** Contains all Phase 0 to Phase 7 recovery deliverables, claim-evidence matrices, research gap analyses, statistical protocols, and manuscript drafts.
4. **`sbg/`:** Contains the original SBG V5 and V6 experimental genome representation source code.
5. **`benchmark/` & `artifacts/`:** Contains the original frozen benchmark datasets, freeze manifests, and evidence JSON files.
6. **`experiments/`:** Contains all historical V5, V8, V9c, and V10 training, evaluation, and diagnostic scripts.
7. **`tests/`:** Contains the automated test suites verifying feature extraction, metric calculations, and pipeline determinism.
