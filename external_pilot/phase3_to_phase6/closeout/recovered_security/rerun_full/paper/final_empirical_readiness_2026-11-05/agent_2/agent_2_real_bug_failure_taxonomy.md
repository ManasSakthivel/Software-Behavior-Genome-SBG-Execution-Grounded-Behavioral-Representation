## 1. Executive Summary & Core Verdict

This investigation conducts an exhaustive forensic audit of the performance of the Software Behavior Genome (SBG V5) on real-world software defects from **BugsInPy** (501 bugs, 55 eligible units, 41 evaluated real-bug positive pairs) and **QuixBugs** (40 benchmark programs, 40 evaluated real-bug positive pairs).

### Key Empirical Findings:
1. **Primary Adverse AUROC Confirmed (Unchanged):**
   - **BugsInPy (canonical output-free v7):** **AUROC = 0.4099** (95% cluster-bootstrap CI: $[0.3262, 0.4939]$, $n=147$ evaluated pairs across 39 clusters).
   - **QuixBugs (canonical output-free v7):** **AUROC = 0.3877** (95% cluster-bootstrap CI: $[0.2847, 0.5034]$, $n=152$ evaluated pairs across 40 clusters).
   - Both primary results are **below chance (AUROC < 0.50)**. These primary figures are frozen and must appear prominently in the primary results section of any publication.

2. **Reconciliation of the Exact-Zero Discrepancy (21 vs 24 vs 26 of 41):**
   - In the committed `pairs_bugsinpy_output_free_v7.jsonl`, exactly **21 of 41 positive pairs** score $\text{SBG V5} = 0.0$.
   - **3 pairs** (`youtube-dl/6`, `youtube-dl/7`, `youtube-dl/26`) had spurious non-zero scores ($0.612–0.681$) in v7 caused by single-process `re` module cache state pollution. When purged with `re.purge()`, their scores drop to $0.0$, bringing the zero count to **24 of 41**.
   - **2 pairs** (`luigi/14`, `youtube-dl/31`) had entry discovery mismatches in v7 (e.g. comparing `float_or_none` against `parse_duration`). When evaluated under the structural rename-invariant entry policy of `output_free_v8`, their scores drop to $0.0$, yielding exactly **26 of 41 zeros**.
   - Additionally, the temporal component alone ($\text{SBG Temporal}$) scored exactly $0.0$ on **26 of 41 pairs** in the committed v7 artifact.

3. **Mechanistic Triad of Real-Bug Failure:**
   - **Fault Unreachability (Input Mismatch):** Fixed synthetic inputs generated by the protocol fail to satisfy program preconditions or branch conditions. In QuixBugs, 20 of 40 programs crash with $100\%$ `TypeError`/`AttributeError` on synthetic inputs before the buggy code is ever executed. In BugsInPy, 21 of 41 positive pairs exhibit identical zero-divergence across all executed paths.
   - **Output Invisibility (Output-Free Constraint):** SAFEGUARD-2 intentionally hides return values. Algorithmic bugs that alter only return values (analogous to synthetic mutation class SC-6) produce identical internal event sequences, yielding distance $0.0$.
   - **Harness & Negative Inflation:** SP-2 function renaming alters the entry signature, causing the harness to score 100% of SP-2 negatives as behavioral changes ($0.20–0.28$ mean distance). Furthermore, 7 BugsInPy SP-2 negatives contain broken call sites resulting in runtime `NameError` (false positives scoring $\sim 0.79$).

4. **Scientific Verdict:**
   SBG V5 **does not demonstrate positive transfer to real-world software bugs** under the output-free, synthetic-input protocol. When harness defects and cache artifacts are isolated in exploratory sensitivity analyses, performance rises to near-chance ($0.444–0.497$, 95% CIs spanning $0.50$). This is a fundamental, defensible method limitation that must be documented honestly.

## 4. Forensic Investigation B: Fault Reachability Analysis

In synthetic benchmarks (V6–V10), transformations are injected into small, self-contained algorithmic kernels where default inputs (`0`, `1`, `""`, `[]`) traverse all branches. In real-world programs, execution reachability collapses:

### Reachability Breakdown:
- **QuixBugs ($N=40$ positive pairs):**
  - **20 programs (50.0%)** crash immediately on 100% of synthetic inputs with `TypeError` or `AttributeError` (e.g. `breadth_first_search`, `bucketsort`, `depth_first_search`, `detect_cycle`, `knapsack`, `levenshtein`, `shortest_paths`). The faulty lines are never reached.
  - **6 programs (15.0%)** crash on $>90\%$ of inputs (e.g. `bitcount`, `minimum_spanning_tree`, `topological_ordering`), exercising only the exception handling prelude.
  - **Total unreached / error-terminated:** **26 of 40 pairs (65.0%)**.
- **BugsInPy ($N=41$ positive pairs):**
  - **21 programs (51.2%)** exhibit zero reference output divergence and identical trace lengths across all synthetic inputs. The specific branch conditions fixed by upstream developers (e.g. handling specific edge-case arguments in `ansible`, `pandas`, `thefuck`, `tqdm`) are never triggered by synthetic scalar/collection inputs.

## 5. Forensic Investigation C: Output Observability & SC-6 Mutation Failures

SAFEGUARD-2 enforces an output-free design to prevent trivial label leakage. However, algorithmic bug fixes frequently alter only computed return values or output formats without changing loop counts or call graphs (the real-world equivalent of synthetic class SC-6).

### Case Studies in QuixBugs:
- **`is_valid_parenthesization`**:
  - Buggy: `return True` (always returns True if loop terminates without underflow).
  - Fixed: `return depth == 0`.
  - Behavior: For non-underflowing strings, the loop runs identically. The only difference is the boolean return value. Because return values are omitted from dynamic traces, $\text{SBG V5} = 0.0$.
- **`max_sublist_sum`**:
  - Buggy: `max_ending_here = max(max_ending_here + x, 0)` vs Fixed: `max(max_ending_here + x, x)`.
  - Same loop iterations, same event stream. Variable updates map to identical state categories $\implies \text{SBG V5} = 0.018$.
- **`bitcount`**:
  - Buggy: `n ^= n - 1` vs Fixed: `n &= n - 1`.
  - Same loop structure; trace length is identical $\implies \text{SBG V5} = 0.0$.

## 6. Forensic Investigation D: State Observability & Abstraction Collisions

The SBG state transition genome maps local variable environments to coarse abstraction bins (e.g. variable types, numerical signs, collection size magnitudes).

1. **Local Variable Renaming & Name Independence:**
   When bugs alter local variable names or intermediate temporary variables without altering the abstract state transition types, the state genome computes zero distance.
2. **Coarse Range Quantization:**
   Small integer adjustments (e.g. `mid = (lo + hi) // 2` vs `(lo + hi + 1) // 2` or `lo < hi` vs `lo <= hi`) frequently remain within identical abstraction bins, producing distance $0.0$.

## 7. Forensic Investigation E: Harness & Label Integrity Audit

The sub-chance primary AUROC ($0.388–0.410$) is driven by an asymmetric failure mode: **the positive class scores near zero due to unreached faults, while the negative class scores non-zero due to harness defects.**

### Key Harness Defects in Negative Class:
1. **SP-2 Function Renaming Artifact ($40/106$ BugsInPy negatives, $40/112$ QuixBugs negatives):**
   - SP-2 renames the target function (e.g. `def foo` $\to$ `def fn_foo`).
   - In v7, the entry selector treats the new name as a signature change, scoring it as a behavioral divergence ($\text{mean distance} \approx 0.275$).
2. **SP-2 Broken Call-Site Defects (7 BugsInPy pairs):**
   - In 7 `youtube-dl` units (e.g. `js_to_json`), a nested helper `fix_kv` was renamed to `fn_fix_kv`, but internal call sites were not rewritten, resulting in runtime `NameError`.
   - These 7 nominally EQUIVALENT negatives score $\text{SBG V5} \approx 0.794–0.800$, creating severe false-positive inflation.
3. **Persistent Self-Distance Anomalies (3 Units):**
   - `black/21` ($\text{self-distance} = 0.6737$), `black/23` ($0.6742$), and `youtube-dl/37` ($0.6040$) exhibit high self-distance even under purged extractions due to global AST/token compiler state inside the traced processes.

### Interpretation:
1. The below-chance primary results ($0.388, 0.410$) are exacerbated by SP-2 harness inflation and global cache state.

3. **Conclusion:** Even after perfect harness decontamination, SBG V5 exhibits **no statistically significant capacity to detect real bugs** under autonomous synthetic input generation.
