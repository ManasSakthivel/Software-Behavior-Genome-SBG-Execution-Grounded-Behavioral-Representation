# Figure and table inventory (Phase 2 manuscript; 7 figures, 15 tables)

All data are exploratory, non-pristine development data. Every item is referenced in the text (checked by script). Figures are generated by `scripts/p2_make_paper_figures.py` (repository root; run `.venv/bin/python scripts/p2_make_paper_figures.py`) from `results/v7b_phase2_summary/` into `results/v7b_phase2_summary/figures/` (new files `fig_p2_*.pdf/png`) and included from LaTeX by the relative path `../../results/v7b_phase2_summary/figures/NAME.pdf` (outside this folder: upload the whole repository to Overleaf or copy the seven PDFs into `figures/` and change the seven `\includegraphics` paths). Graphviz `dot` is not installed, so the architecture and verdict-flow diagrams are drawn with matplotlib; the old `figures/*.dot` sources are kept but NOT used by the paper.
