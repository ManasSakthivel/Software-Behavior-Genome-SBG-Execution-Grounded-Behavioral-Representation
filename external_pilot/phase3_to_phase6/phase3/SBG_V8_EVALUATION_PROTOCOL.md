Registered: 2026-11-20 (before any pilot execution; none has been run in this programme).

Project gate: `~/Desktop/SBG-V8-LINUX/research/v8_final_design/11_FINAL_RESEARCH_GATE.md` requires explicit user authorisation for Phase 3 and a freeze sign-off. The user's instruction to run Phases 3–6 is recorded as the authorisation. **The freeze sign-off is outstanding.**

## 1. Observation boundary (unchanged)

`O = {outcome, exception, side_effect, api}`, as defined in `research/v8_final_design/04_FORMAL_PROBLEM_DEFINITION.md`. Not expanded or redefined.

## 2. Research questions

- **RQ1.** On authentic, single-file historical bug-fix pairs with a verified regression test, does frozen SBG V8 report a divergence?
- **RQ2.** How often does frozen SBG V8 report no divergence (false assurance) on those pairs?

## 3. Hypotheses

- **H1 (RQ1).** Detection rate on positives is at least 0.80, and the 95% Wilson lower bound is at least 0.50.
- **H2 (RQ2).** False-assurance rate on positives is below 0.20.

These thresholds were chosen before pilot execution. With n ≤ 15 the Wilson interval is wide (for 15/15 the lower bound is about 0.80, and for 12/15 about 0.55). Any result from a cohort this size is descriptive; no conclusion about broad validity follows.

## 4. Dataset and eligibility

- Source: Phase 2 shortlist (`audit/phase2/PILOT_CASE_SHORTLIST.md`), 15 cases.
- Inclusion: reproduced at parent (defect demonstrated) and passing at fixed; single source file; independent repository and case per Phase 2 checks.
- Exclusion: any case the frozen package cannot execute; multi-file changes; cases whose regression test calls an API absent at the parent (ImportError).
- **Current status: no case is eligible for execution.** The frozen package has no input generator for external modules (`PHASE2_FINAL_REPORT.md`, open gap 1). Hand-written per-case inputs are forbidden by the brief. Therefore the executed cohort is **0** and H1 and H2 are **not tested**.

## 5. Ground truth

- Reference divergence for a case: the regression test passes at fixed and fails at parent for the defect (Phase 2 reproduction).
- The regression-test input is **not** given to SBG. SBG's own inputs are to be generated by the frozen package. Recording whether SBG's inputs fall inside the defect region is an allowed secondary analysis.
- Negatives: no authentic negatives are available in the shortlist. Formatting-only commits would be candidate negatives but need human adjudication; none is included. No mutation or synthetic negative is used.

## 6. Outcomes and metrics

- **Primary:** detection rate on positives, `TP / (TP + FN)`, with 95% Wilson CI.
- **Secondary:** false-assurance count (no-divergence verdicts on positives); distribution of verdicts (DIVERGENT, SAME, INCONCLUSIVE, INSUFFICIENT); execution failures; runtime and memory.
- Precision, specificity and false-positive rate are **not estimable** without negatives. They will not be reported as results.

## 7. Missing, inconclusive and failed cases

- Inconclusive, insufficient and execution-failure outcomes are counted in the denominator of the primary outcome as non-detections. They are never counted as successful detections.
- Each exclusion is listed with its reason.

## 8. Statistical methods

- Wilson 95% CI for proportions.
- Cases from the same repository are clustered; results are reported per repository. No claim treats repositories as independent samples beyond descriptive reporting.
- No multiple-comparison correction is needed for a single confirmatory test. Ablations and sensitivity analyses are exploratory.

## 9. Threshold and configuration

- Decision threshold: τ* = 0.072905 from `artifacts/final/THRESHOLD_FROZEN.json`. Not re-derived or re-tuned on pilot data.
- Execution: macOS, CPython 3.13.15, `sandbox-exec` isolation (declared in `REPRODUCIBILITY.md`). Linux/Docker isolation is listed by the project as not reproduced; this programme does not claim it.

## 10. Preregistered analyses

**Confirmatory (preregistered):** H1 and H2 only, on the eligible cohort.

**Exploratory (not preregistered):** per-repository breakdown, verdict distribution, runtime, ablations, sensitivity to τ*, and the defect-region check in §5.

## 11. Human adjudication (Phase 5)

Two independent human reviewers are required. None has been recruited. The adjudication package and handbook are prepared but **not** completed. Model-generated or internal agent reviews are not substitutes and will not be counted.

- Declared environment is macOS; the "LINUX" name of the repository is not an execution claim.
