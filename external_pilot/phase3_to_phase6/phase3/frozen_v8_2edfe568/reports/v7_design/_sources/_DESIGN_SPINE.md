## Recommended core thesis (to be challenged)
V7 is a WITNESS-BASED, SUFFICIENCY-AWARE cross-version divergence system, not a learned scorer. Verdict per (old,new,scope) is three-valued: DIVERGENT (carries a replayable witness input + first-divergence locus + evidence chain), NO_DIVERGENCE_OBSERVED (with an explicit observation-sufficiency level: changed-region activation, state-coverage, budget; NEVER 'equivalent'), INSUFFICIENT/UNKNOWN (with reason code). Equivalence is only asserted by an optional formal tier (bounded symbolic / regression verification) on small units.
Representation (hybrid, selected to be tested against alternatives): immutable content-addressed event log = ground truth; derived views (control-flow, call, data-dependence, state-transition system over abstracted states) are deterministic projections, not stored truth. Alignment = static (AST/CFG) matching seeded by dynamic anchors; divergence = first-divergence + per-view comparison along aligned traces; impact = dynamic dependence propagation from the first divergence (labelled as observed dependency, not causal proof).
Core modules: A exploration (replay + structure-aware/property-based generation + changed-region-directed scheduling; no labels), B execution capture (sandbox, determinism control, completeness metadata), C static context (minimal: AST/CFG, changed regions, signatures), D evidence fabric (content-addressed immutable log + provenance), E state/invariant engine (simple relational invariants and state abstraction, optional), F multi-view graph engine (projections), G alignment, H divergence+impact, I evidence/uncertainty/decision (three-valued verdict, sufficiency, selective prediction), K validation harness, L reproducibility/governance. J (learned prediction) is OPTIONAL and non-core; no GNN/LLM dependency. Concolic/symbolic = optional selective extension for activation of hard branches and for the formal tier.
Baselines that V7 MUST beat or match to be worth building: plain differential testing with the same budget (output equality), coverage-guided differential fuzzing, conventional features (edit size, token/AST distance, exec volume), V5, V6. The scientific question for V7: does internal-state/trace divergence plus sufficiency-aware abstention add information beyond output-differential testing at equal budget (e.g. earlier detection of masked divergences, calibrated 'insufficient', fewer false assurances)?
Strongest known argument against: it may reduce to differential testing + coverage; value of internal-state divergence beyond outputs is unproven; real-bug ground truth is scarce and noisy.
