# SBG V6 — Research and Novelty Positioning
Claimed (to be tested, not assumed): (N1) a name-free, confidence-weighted invariant-set distance between program versions (Daikon-grounded) used as a behavioural-change score; (N2) an evidence layer separating ACTIVATED / NOT_ACTIVATED / UNKNOWN so missing observation is never read as equivalence; (N3) change-activation gating linking diff lines to executed lines; (N4) an evaluation protocol pairing every SBG model with a same-family conventional model, a reversed-edit-size control and a differential-testing baseline.
Not claimed: a new invariant inference algorithm; semantic equivalence checking; defect detection; cross-language validity; superiority over differential testing when outputs are available.
Prior-art overlap: Daikon (invariants), Chianti (affected tests), spectrum methods (coverage), differential symbolic execution (semantic gold). Novelty is the combination and the honest evaluation, which may turn out negative.
